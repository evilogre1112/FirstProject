# 🚀 Hướng Dẫn Setup GitHub Profile README

## Bước 1: Tạo Repository đặc biệt

1. Truy cập [github.com/new](https://github.com/new)
2. **Repository name**: nhập chính xác `evilogre1112` (trùng với username của bạn)
3. Chọn **Public**
4. ✅ Tick **Add a README file**
5. Click **Create repository**

> ⚠️ Repository PHẢI có tên trùng với username thì GitHub mới nhận diện nó là profile README!

---

## Bước 2: Thêm nội dung README

1. Mở repository `evilogre1112/evilogre1112` vừa tạo
2. Click vào file `README.md` → Click nút **Edit** (biểu tượng bút chì ✏️)
3. **Xóa hết nội dung cũ**, copy toàn bộ nội dung từ file `GITHUB_PROFILE_README.md` mà tôi đã tạo
4. Paste vào editor
5. Click **Commit changes**

---

## Bước 3: Setup Snake Animation 🐍

Đây là bước để con rắn ăn contribution graph hoạt động:

1. Trong repository `evilogre1112/evilogre1112`, tạo folder:
   ```
   .github/workflows/
   ```
2. Tạo file mới tại `.github/workflows/snake.yml`
3. Copy nội dung từ file `snake.yml` mà tôi đã tạo, paste vào
4. Commit changes

### Chạy workflow lần đầu:
1. Vào tab **Actions** trong repository
2. Click vào workflow **"Generate Snake Animation"**
3. Click **"Run workflow"** → **"Run workflow"** (nút xanh)
4. Đợi workflow chạy xong (khoảng 1-2 phút)

> Sau đó workflow sẽ tự chạy mỗi ngày lúc 0:00 UTC

---

## Bước 4: Cập nhật thông tin cá nhân

Trong file `README.md`, tìm và thay thế các placeholder:

| Placeholder | Thay bằng |
|---|---|
| `YOUR_FACEBOOK` | Username Facebook của bạn |
| `YOUR_DISCORD_ID` | Discord ID của bạn |
| `your.email@gmail.com` | Email thật của bạn |
